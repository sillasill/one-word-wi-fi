One word, 9 characters: the funniest and most accurate description of home
Wi-Fi, judged head to head by an AI. It personifies the network as an
employee who only ever works part-time — there when you don't need it, gone
the moment it matters.

Entry for the make.fun bounty
[One Word for Your Wi-Fi](https://make.fun/bounty/u-tuan-muda-one-word-for-your-wi-fi-a1b4fd72).

## Run

```sh
node main.ts
```

Writes the word to `/output/entry.txt`. Deterministic, standard library
only, no network, no API keys.
